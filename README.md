# 🥘 RecipeMatch
Personalized Recipe & Cooking Assistant Platform


**Personalized Recipe & Cooking Assistant Platform**

RecipeMatch is a personalized web application that helps users discover recipes based on their cooking preferences, dietary needs, available equipment, and ingredient limitations. Users create a profile that enables the platform to recommend personalized meals, peer-led cooking classes, and nutritional guidance.

The app streamlines the cooking experience by eliminating common frustrations like long blog-style recipe pages, irrelevant dietary suggestions, or inaccessible appliances. Users can swipe through AI-curated recipes, save them to a digital cookbook, join live or asynchronous cooking classes, and get tailored grocery suggestions.

The full stack version of RecipeMatch will include real user authentication, recipe storage, profile customization, peer-assistance scheduling, and AI-based meal recommendations powered by user data.


### 🔧 Tech Stack
- **Frontend**: React or Next.js, HTML, CSS  
- **Backend**: Node.js with Express.js  
- **Database**: Firebase Firestore (or PostgreSQL)  
- **Authentication**: Firebase Auth  
- **APIs**: Spoonacular API *(for mock recipe data)*  
- **Deployment**: Vercel or Heroku

### 📁 Features (Planned)
Personalized onboarding (cuisines, dietary style, appliances)
- Swipe-based recipe discovery
- Detailed recipe cards (ingredients, nutrition, equipment)
- Save and organize recipes in a personal Cookbook
- Create shopping lists based on goals (e.g. weight loss, high protein)
- Book cooking classes or peer diet assistance
- Real-time chat and follow-up notes
- AI-powered recipe curatio
